SmartSearch training – practice exercises
=========================================

What's in this folder
---------------------
index.html          Training area (start here)
ask-terms.js        Extra words and phrases for the Ask the training box (edit on GitHub)
todo-create.html    To-Dos module: Create a To do

Every page is a single self-contained file (images included). The pages
link to each other by file name, so keep all the files together in one
folder and don't rename them.

Hosting
-------
Upload every file to the same folder on the web host and share the
address of index.html. Keep all pages on the same domain so that
progress tracking works across exercises.

Progress tracking
-----------------
When an exercise is finished, it is recorded in the learner's browser
(localStorage, key "smartsearch-training:progress"). This is separate
from the Credas Connect training, so the two never mix. Music on/off is
stored under "smartsearch-training:music". Learners can reset progress
with "Clear my progress" in the training area.

Progress belongs to that browser on that device: it isn't sent anywhere,
isn't visible to trainers, and is lost if the learner clears their
browser data or uses a private/incognito window.

Devices and browsers
--------------------
Current Chrome, Edge, Safari and Firefox on Windows, Mac, iPad and
Android tablets. Best on a laptop, desktop or tablet.

The "Listen to overview" voice uses each browser's built-in voice;
Microsoft Edge has the most natural UK voices.

All names, companies and dates in the exercises are made up.
